# Report for Exp15: ToDo Task Manager Using Django

## Experiment 15: ToDo Task Manager Using Django

Developed a ToDo Task Manager web application using Django and Python.
Created a task management webpage using HTML and CSS with a modern, dark-themed user interface.
Implemented functionality to add, view, edit, search, complete, and delete tasks.
Integrated date and time functionality to record task creation timestamps and set deadlines.
Implemented task filtering to display all, pending, completed, and overdue tasks.
Used Django models and an SQLite database to store and manage tasks persistently.
Used ChatGPT to understand Django concepts, implement features, and troubleshoot errors.

- Understanding Django's project structure, models, views, and URL routing.
- Connecting the frontend templates with backend functionality.

- Adding date and time fields and handling task deadlines.
- Resolving URL configuration errors during database migrations.
- Managing database changes using Django migrations.
