# Experiment: Server-Side JavaScript using Node.js and Express.js

## Aim

To understand and implement server-side JavaScript using Node.js, build RESTful APIs with Express.js, handle HTTP requests and responses, work with URL parameters and POST data, implement EJS templating, and use development tools like Nodemon.

## Objectives

1. Understand server-side JavaScript using Node.js.
2. Create a web server using Express.js.
3. Handle HTTP GET and POST requests.
4. Work with URL parameters.
5. Process POST form data.
6. Create RESTful API endpoints.
7. Render dynamic webpages using EJS.
8. Use Nodemon for development.

## Technologies Used

- Node.js
- Express.js
- EJS
- Nodemon
- HTML
- CSS
- JavaScript
